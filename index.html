🚀 What caddy Does for You

caddy is a web server. In simple terms, a web server is the program that holds the files of a website and hands them to anyone who visits your web address. Every website you have ever opened was delivered to your screen by a web server.

What makes caddy special is the word you see everywhere in its name: automatic. Normally, setting up a website involves a long list of technical chores, including the famous security certificate that makes the little padlock appear in a browser. With caddy, that work is handled for you. You describe what you want in a plain, readable text file, and caddy takes care of the rest.

It works on Windows, macOS, and Linux, it is fast enough for busy sites, and it supports the newest versions of the technology browsers use to load pages safely.

✨ Key Features

  • Automatic HTTPS: caddy requests and renews your security certificate by itself, so the padlock appears without you lifting a finger.
  • Privacy by default: your site is encrypted from the moment it goes live, and your visitors' browsing stays private.
  • Fast on every connection: caddy speaks the modern versions of the web's language, including HTTP/3, which loads pages quickly even on weak Wi-Fi.
  • Reverse proxy built in: you can point one web address at another program running on your computer and let caddy handle the safety layer in front of it.
  • A readable configuration file: the Caddyfile is a short, human-friendly text file that describes your site in a few clear lines.
  • Multi-platform: the same application runs on Windows, Mac, and Linux, so your notes and setup carry over.
  • One small program: there is no sprawling control panel to learn and no separate database to install.

🔒 Automatic HTTPS in Plain English

When you send a letter, you would rather put it in a sealed envelope than on a postcard. HTTPS is that sealed envelope for the web. It scrambles the information travelling between your visitor and your site so nobody in between can read it.

To prove the envelope is real, a browser looks for a certificate issued by a trusted authority. Obtaining those certificates used to be a fiddly process with expiry dates you had to remember. caddy talks to the certificate authority for you, receives the certificate, installs it, and quietly renews it whenever it gets close to expiring.

The practical result: browsers stop showing warnings, search engines are happier, and your visitors feel safe. This is the part of running a website that most people dread, and caddy removes it entirely.

🌐 What a Reverse Proxy Means

A reverse proxy is a polite doorman. Visitors arrive at the front door, and the doorman decides which room inside the building they should be taken to. Your visitors never need to know there are several rooms behind the door.

People use this when one address should serve a website, another should reach a small program running on the same computer, and a third should reach something else again. caddy stands at the front, keeps every connection encrypted, and passes each visitor to the right place.

You describe these rules in the Caddyfile, which reads like a short shopping list rather than computer code. A web address goes on one line, and a description of what it should do goes underneath.

🛠️ Common Questions

Do I need to know how to program?

No. You need to be comfortable saving a text file and double-clicking a program. The configuration language is designed to be read out loud and understood.

Is caddy free to use?

Yes. caddy is open source software, which means the source code is public and anyone may inspect it, use it, or contribute to it. There is no licence key to buy.

Will it work on my computer?

caddy is built for many platforms, including Windows, macOS, and Linux. The download page lists the releases so you can choose the one that matches the computer you are sitting at.

What is the Caddyfile?

It is a plain text file holding your settings. You write the address of your site, and beneath it the few things you want caddy to do. Because it is plain text, you can open it in Notepad and read it at any time.

Why does a black window stay on my screen?

That window is the running program. It shows messages about what it is doing. If you close it, the server stops and your site becomes unreachable. Minimise it instead of closing it.

Is my visitors' privacy protected?

Encryption is switched on automatically, so the traffic between your visitor and your server cannot be read along the way. caddy also avoids unnecessary logging by default, which keeps your visitors' details out of your files.
